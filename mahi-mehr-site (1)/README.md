# Mahi Mehr Kashan — static site

Deploy: push to a GitHub repo (branch `main`), then Settings → Pages → Source: GitHub Actions.
Replace `YOUR-DOMAIN` in `robots.txt` and `sitemap.xml` with the real address.
Photos: put `001.png`… in `photos/` (see `photos/LIST.csv`). Real photos only; keep illustrations separate.
Not built yet: contact form backend, AI assistant (needs a serverless endpoint + secret key, never in this repo).
